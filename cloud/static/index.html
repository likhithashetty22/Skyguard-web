SkyGuard AI System Architecture

1. AWS Sensor Simulation (Sender Node): Captures temperature, humidity, pressure, and calculates signal parameters (RSSI, SNR, Latency).

2. Edge Gateway (Receiver Node): Evaluates real-time threshold spike rules and TinyML verdicts via client-side BroadcastChannel.

3. Central Cloud Pipeline (FastAPI Backend): Ingests telemetry, persists data in SQLite, streams hardware metrics, and executes PyTorch Autoencoder retraining.

Privacy Policy

SkyGuard AI operates as an enterprise telemetry demonstration system. All stored logs are retained locally or within the designated SQLite deployment database. No personal identifying information is transmitted to third parties.
